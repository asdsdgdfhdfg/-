# 爬虫岩石造景图片处理固定规范（必须严格遵守，不得自行改动）

## 输入

用户提供任意带鱼缸/缸壁/顶灯/底材/植物的爬虫岩石造景实拍图，按以下规则处理。

用户已于 2026-10-16 明确确认：以后这类岩石造景均默认采用下述砂岩材质、颜色和光影，有额外要求会主动提出。直接执行，无需每次询问风格。当次明确要求优先于默认规范。

## 基础统一要求（所有视角必做）

1. 背景：纯净纯白色，无渐变、无阴影背景、无环境杂物；禁止出现外置独立底板、外置背板、桌面、台面。
2. 落地：整组造景底部平直自然落地，仅在接触位置保留极淡柔和浅灰色接触阴影，无浓重投影。
3. 保留内容：完整保留原图所有前景岩石造型、洞穴/拱门孔洞、层叠台阶轮廓、可辨识的岩层、裂隙与风化纹理、大小比例与相对位置，同时完整保留后方整面连续岩石背板（岩壁凹凸、沟壑肌理不删减）。材质颜色统一采用下述已确认风格，除非用户另有要求。
4. 删除内容：移除全部鱼缸黑色边框、前后透明缸壁、顶部灯带/顶灯、沙/木屑/树皮等所有底材、所有杂草植物、枯枝，无任何文字、水印、logo。
5. 材质与光影：默认采用自然风化的赭红砂岩、琥珀色定向暖光和深褐阴影，具体按下节执行。白底与极淡落地阴影保持不变，灯光与体积阴影主要体现在岩石本体。

## 默认材质、颜色与光影（用户已确认，后续同类造景统一采用）

确认依据：用户提供的“豆包 (8).png”材质和灯光参考，以及明确认可的成图“rockscape-front-05-amber-sandstone.png”。以下文字标准独立可用，不依赖历史聊天或临时文件。

1. 材质：自然干燥、哑光的风化砂岩。清楚表现沉积层理、自然裂隙、崩口及中尺度岩面起伏；较平整的岩面保持连续、细腻，细砂质微纹理克制自然。保留原造景宏观结构，不照搬风格参考中的岩石布局。
2. 颜色：赭红、赤褐、陶土色、熟赭与深棕色为石材基调；受光面呈琥珀金暖色，背光面为浓郁深褐色。允许从原图颜色转换到这套配色，不能机械执行旧版“保持原色”。颜色应有材质层次，不能只整图叠加橙色滤镜。
3. 主光：画面外上方略偏左前侧的暖琥珀定向光，可用克制的右上辅助光。顶部岩台和朝上的岩脊出现有方向、有落差的暖色受光区域，光沿岩层掠过；不出现灯具或可见光束。
4. 光影：保留明显的暖亮面与深褐暗面分离，以及岩台下方和洞穴内的自然体积阴影。受光与衰减按较大岩块、台阶和凹面组织，过渡自然；不做均匀提亮、平淡无影棚光或苍白米色效果，也不对每个细粒加黑白描边。
5. 明暗细节：亮面仍可辨认岩层和裂隙，无爆白高光；洞口边缘和附近岩面有少量漫反射层次，洞穴深处可自然较暗，不要求每个角落同样明亮。不把暗部提成平灰，不出现湿润油亮或塑料反光。
6. 低噪质感：清晰度来自有效岩层、裂隙和边缘，不靠堆叠细碎颗粒。抑制密集噪点、椒盐点、蚯蚓状伪纹理、重复浮雕感、粗砂覆盖感及全局过度锐化；同时避免磨皮成蜡面，保留真实粗粝程度。
7. 范围与例外：上述风格只作用于造景本体；纯白背景、平直落地、结构保留及清理要求仍执行，不复制风格参考中的暗背景、沙地、植物和摆设。指定侧视/后视的刀切面仍无纹理，仅匹配模型的砂岩基色和合理受光。用户有额外要求时按当次说明调整。

## 清晰度与细节还原（所有视角必做）

用户确认的长期标准：达到其提供的“豆包 (7).png”参考图所示的清晰程度。参考图用于说明岩石层理、裂隙、颗粒和边缘的可辨识程度，不借用其造型、颜色、布光、背景阴影或水印。其原始尺寸为 2819×1487；像素尺寸不能替代真实细节质量。

1. 清晰度：前景岩台、完整后方岩壁和洞穴附近均保持全景深清晰。岩层分界、细小裂纹、凹槽、风化颗粒、崩口和台阶薄边应自然可辨，不能只让外轮廓清楚而表面模糊。
2. 模糊修复：对失焦、压缩、低分辨率或暗部遮蔽造成的不可辨区域，主动依据同一造景邻近的岩层走向和纹理尺度，结合默认砂岩材质与配色合理重建微细节，形成连续可信的岩石表面；不得原样保留糊块、涂抹状区域或死黑无层次的洞穴入口。补全不能变成全表面均匀加颗粒。
3. 结构约束：细节补全不得改变岩块数量、轮廓、厚度、台阶走向、孔洞形状与大小、相对位置或整面背板。原图确实无法辨认的微细节属于合理重建，不得声称是原始细节的精确恢复。
4. 纹理质感：保留自然粗粝感和细微明暗层次，避免磨皮、蜡感、塑料感、重复贴图、无依据的新大裂缝，以及用随机噪点冒充颗粒。禁止过度锐化产生白边、黑边、光晕或脆硬锯齿。
5. 暗部表现：在定向暖光与克制补光下，让洞口边缘、洞内可见岩面及岩层交界仍有细节和深浅层次，深洞内部允许自然较暗；保留合理洞穴深度，不把深洞提成平灰色，不把有岩壁的凹洞变为白色贯穿孔。
6. 输出质量：优先使用工具支持的最高可用原生分辨率，保存高质量 PNG。不能仅靠插值放大、提高像素数或全局锐化充当细节还原；应在图像编辑阶段明确要求重建模糊区域的岩石微细节。
7. 多视角例外：上述岩石纹理要求适用于应保留纹理的岩石表面；指定侧视的刀切侧面和正后视的刀切背面仍必须保持无纹理的平直纯色面，边界清晰即可。

## 默认输出：正交正面视角

1. 先矫正斜拍透视：消除近大远小、侧边倾斜、透视收缩，改为正交平行投影。
2. 所有竖直岩壁边缘绝对竖直、左右平行；所有水平岩层水平平行。
3. 整体外轮廓为平直横向矩形块，可垂直平整贴入方形鱼缸后壁，无透视畸变。

## 多视角生成规则（用户要求侧视/后视时执行）

1. 左45度 / 右45度侧视：正面岩石结构完整保留；朝向画面的可见侧面为完全平直竖直的纯色刀切平面，无纹理、无凹凸、无岩石细节，和模型同色。
2. 正后视图：整个背面为完全平直竖直纯色刀切平面，无纹理、无孔洞、无凹凸，仅上边缘外轮廓保留原正面的自然剪影起伏，整体为竖直矩形实体块。
3. 所有视角底部平直落地，白底，采用默认砂岩配色与定向暖光，无多余元素。

## 禁止项

禁止自行添加植物、装饰、道具、文字；禁止改变岩石造型结构；禁止保留缸体、灯具、底材；禁止出现透视畸变；禁止使用深色/彩色背景。

## 执行与检查

- 以用户提供的原图为编辑参考；未指定视角时直接使用默认正交正面视角。仅在用户要求时生成指定侧视或后视。
- 使用可用的图像编辑工具，并遵守其参考图输入要求；本地图像先查看再编辑，避免脱离原图重新设计造景。
- 明确参考图角色：原图锁定结构；已确认风格参考指导砂岩材质、颜色与光影；清晰度参考仅指导有效细节和边缘辨识度。若无法访问历史图片，按本文独立文字标准执行，不假称已查看历史图片。
- 将上述固定规范和本次指定视角完整纳入编辑要求。检查前景结构、孔洞、层叠台阶、完整岩石背板、材质颜色，以及白底、接触阴影和清理结果。
- 保留原有连续岩石背板；“禁止外置背板”指不得新增独立外置背板。指定侧视或后视的刀切平面按对应视角规则执行。
- 如生成结果出现可见偏差，依据原图和具体偏差修正；未实际核验的结构一致性不得声称已经验证。
- 提示词须明确包含“锁定原有结构、赭红哑光风化砂岩、琥珀定向暖光、深褐体积阴影、清楚自然的层理/裂隙/崩口、克制细砂微纹理、低噪点、对模糊区域合理补全、纯白背景”，不能只写“高清”或“4K”，也不要堆叠极致颗粒或过度微细节要求。
- 交付前同时检查整图和原始尺寸下的局部：至少查看层叠台阶边缘、背板沟壑、洞口及暗部可见岩面，确认无糊块、涂抹、重复纹理、锐化光晕和结构漂移；只有缩略图清楚不算达标。参考图仍可访问时用于清晰度对照，不作为造型编辑目标。
